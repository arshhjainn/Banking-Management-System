# Programming concepts map

The project uses Python for its programming concept examples. Run each independently with `python3 python-demonstrations/<filename>.py`.

| File | Concepts demonstrated |
|---|---|
| fundamentals_demo.py | Numeric/string types, operators, branching, loops, conversion, lists |
| class_and_object_demo.py | Classes, objects/references, initialization, methods, parameters, returned objects, class data |
| inheritance_demo.py | Abstract base, inheritance, overriding, runtime dispatch |
| inner_class_demo.py | Nested classes and instance association |
| recursion_demo.py | Recursion and a base case |
| console_demo.py | Console input and output |
| file_handling_demo.py | Text file read and write |
| exception_demo.py | Raise/propagate, try/except, custom exception |
| thread_demo.py | Threads, synchronized condition, notification, cooperative cancellation |

These examples are separate from the Flask web API and use Python’s own language features.
